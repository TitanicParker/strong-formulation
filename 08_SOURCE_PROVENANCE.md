# Source Provenance

The flat repo is compiled from a family of TitanicParker case repositories. Source repositories are evidence of research lineage, not independent factual authorities.

## Primary compilation base

- `TitanicParker/strong-formulation` — canonical forensic record, structured evidence/timeline/claims/knowledge/profile datasets, Professional Fork and final presentation/validation layer. Base commit for this compilation: `7e4e8976d881c99d68f0df3f1d68302f246eee29`.

## Evidential architecture sources

- `TitanicParker/case-evidence-ledger` — fact/proposition registers, expert questions, defence/adverse-case audits, Podiatry SAR work, schema/validation architecture.
- `TitanicParker/clinical-documentary-case` — compact facts/propositions/clinical-argument/expert-question/tensions decomposition.
- `TitanicParker/for-counsel` — controlling reconstructions, current-case-position papers, authority/partition/impeachment analysis, restored-Protest dependency audit and deep adversarial review.

## Provenance rule

Every factual proposition must resolve to a primary record, admissible witness account or expressly labelled derivative reconstruction. A proposition does not become better evidence because it appears in multiple repositories copied from the same source.
