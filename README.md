## Core theory

The case is not that a later diagnosis proves earlier negligence. The viable question is whether, once the originating painful-foot problem was expressly restored before closure, the assessment, reasoning, documentation, handover and follow-up response were ones an ordinarily competent specialist could reasonably have adopted on the information then available; and, separately, whether later evidence created further occasions on which the inherited formulation should reasonably have been reconsidered.

This repository separates fact, inference, expert opinion, breach, causation, damage, limitation, complaints, professional standards and GDPR.
